核心概念

术语定义
Gateway (API 网关)所有外部请求的统一入口，负责路由转发、认证鉴权、限流。本项目用 Spring Cloud Gateway 实现。
Service Discovery (服务发现)服务实例动态注册和发现。服务启动时向注册中心报备，调用方通过服务名而非 IP 寻址。本项目用 Nacos。
Load Balancing (负载均衡)将请求分发到多个服务实例。Spring Cloud LoadBalancer 与 Nacos 集成，配合 lb:// 前缀使用。
Circuit Breaker (熔断器)当下游服务持续失败时快速返回错误，避免请求堆积。本项目用 Resilience4j。
Distributed Transaction (分布式事务)跨多个服务/数据库的事务一致性。本项目用 Seata AT 模式，通过 undo_log 表实现自动回滚。
Message Queue (消息队列)服务间异步通信，解耦生产者和消费者。本项目用 Kafka，场景：库存入库后自动生成应付账款。
Distributed Tracing (链路追踪)在跨服务调用链中跟踪请求。每个请求带唯一 TraceId，可在 Zipkin 中查看完整调用链路。
Feign (声明式 HTTP 客户端)通过 Java 接口 + 注解定义远程调用，OpenFeign 自动生成实现。配合 LoadBalancer 实现服务名寻址。
JWT (JSON Web Token)无状态认证令牌。用户登录后签发，后续请求在 Authorization 头中携带，Gateway 层统一校验。
