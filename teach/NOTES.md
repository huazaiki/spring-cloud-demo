 # Teaching Notes

 - **Quiz before next lesson:** After completing each lesson, ask the user questions to verify understanding before advancing. Use retrieval practice. Wait for correct answers or discussion before offering the next lesson.

- **讲解优先于实现：** 每课应侧重于"为什么"和"怎么想"，概念讲解 > 设计思路 > 代码示例。减少 step-by-step 的操作指南和项目状态清单。
