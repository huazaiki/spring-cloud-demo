 # Mission: Spring Cloud 微服务

 ## Why
 掌握 Spring Cloud 生态的核心组件和设计思想，能够独立设计、搭建和运维一个生产级微服务系统。当下就是通过这个 Procure-to-Pay 项目，把 Gateway、Nacos、OpenFeign、Seata、Kafka 这些组件真正吃透 —— 不只是会用，而是理解它们各自解决什么问题、什么时候该用、什么时候不该用。

 ## Success looks like
 - 能把本项目每一行配置、每一个组件选型解释清楚为什么这样设计
 - 能独立从一个空 Maven 项目开始，搭出一套包含网关、注册中心、服务间调用、分布式事务的微服务体系
 - 能在面试或实际工作中，对 Spring Cloud 微服务架构做出有判断力的技术决策

 ## Constraints
 - 学习材料以本项目代码为第一手资料，外部分引用官方文档和经典文章
 - 每次 lesson 控制在 10 分钟内可读完，重在理解而非记忆

 ## Out of scope
 - Kubernetes / 容器编排（Docker Compose 够用）
 - 前端（frontend-demo 不深入）
 - Spring Cloud 之外的微服务框架（如 Go-Micro、Dubbo 独立体系）
