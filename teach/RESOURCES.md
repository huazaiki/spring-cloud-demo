 # Resources

 ## Primary (highest trust)

 - [Spring Cloud 官方文档](https://spring.io/projects/spring-cloud) — 组件选型、配置参考的第一来源
 - [Spring Cloud Gateway 文档](https://docs.spring.io/spring-cloud-gateway/reference/) — 路由、过滤器、限流
 - [Nacos 官方文档](https://nacos.io/docs/latest/overview/) — 注册中心与配置中心
 - [Seata 官方文档](https://seata.apache.org/docs/) — AT 模式、TCC 模式
 - [Resilience4j 文档](https://resilience4j.readme.io/) — 熔断、限流、重试
 - [Spring Cloud OpenFeign 文档](https://docs.spring.io/spring-cloud-openfeign/reference/) — 声明式 HTTP 客户端

 ## Secondary (community & deep dives)

 - [Microservices Patterns (Chris Richardson)](https://microservices.io/patterns/) — 微服务模式图谱
 - [Martin Fowler: Microservices](https://martinfowler.com/articles/microservices.html) — 经典文章，说清楚了"为什么"
 - [Building Microservices (Sam Newman)](https://samnewman.io/books/building_microservices_2nd_edition/) — 推荐书籍
